Assignee completion is intentionally narrower than ownership. The SECURITY DEFINER RPC validates the authenticated user is still the task's current assignee and still belongs to the task's Household while holding the row lock. It only changes `completed`, the mirrored `data.completed`, and `client_updated_at`. Existing creator-only task UPDATE/DELETE RLS policies remain unchanged. Migration 015's existing `planly_tasks` UPDATE trigger provides the Household broadcast/reconciliation notification.
