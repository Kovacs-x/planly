UI contract: incoming creator-owned Household tasks remain read-only by default. Only when the task's `assigneeId` matches the authenticated Household user does the hardening layer enable the existing completion circle. The card still has no edit/delete/actions control. Tapping the circle is intercepted before the core app's owner mutation handler and calls the narrow completion RPC.
